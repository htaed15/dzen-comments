# Чек-лист перед сдачей

Мой список для самопроверки по тексту задания. Отмечено то, что я проверил сам, пройдя приложение руками и запустив тесты.

## Обязательное

- [x] Django и Django ORM
- [x] Реляционная БД (PostgreSQL)
- [x] ООП: сервисные классы (очистка HTML, CAPTCHA, правила имён, файлы)
- [x] Данные о пользователе (имя, e-mail, IP, браузер) сохраняются в БД
- [x] Vue на фронтенде
- [x] WebSocket: новые комментарии появляются без обновления страницы
- [x] Docker: приложение со всем окружением запускается через `docker compose up`
- [x] Git, история с ветками

## Форма

- [x] User Name: латиница и цифры, обязательное
- [x] E-mail: формат e-mail, обязательное
- [x] Home page: формат url, необязательное
- [x] CAPTCHA: картинка, латиница и цифры, обязательное
- [x] Text: только разрешённые теги, обязательное
- [x] Проверка на клиенте и на сервере
- [x] Предпросмотр без перезагрузки страницы
- [x] Кнопки `[i]`, `[strong]`, `[code]`, `[a]`

## Теги и регулярные выражения

- [x] Разрешены `<a href title>`, `<code>`, `<i>`, `<strong>`, остальные вырезаются
- [x] Проверка закрытия тегов
- [x] Валидный XHTML: нижний регистр, кавычки у атрибутов, у `<a>` обязателен `href`

## Главная страница

- [x] Ответы на комментарии без ограничения глубины
- [x] Заглавные комментарии таблицей
- [x] Сортировка по User Name, E-mail, дате в обе стороны
- [x] Сортировка по умолчанию LIFO
- [x] По 25 комментариев на странице

- [x] Простой дизайн на CSS
